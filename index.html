Employee Task Assignment

DAA Hackathon | Design and Analysis of Algorithms

Problem Statement

A company has several employees and tasks. Each employee requires a different amount of time to complete each task. Every task must be assigned to exactly one employee, and each employee can handle only one task. The goal is to find an assignment that minimizes the total completion time.

Algorithm / Approach

Step 4: Compare the assignment times.
Step 5: Select the assignment with minimum total time.
